# reCodex ESP32-S3 烧录工具

双击项目根目录的 `reCodex-Flasher.exe`。EXE 已包含 Python 和烧录依赖，无需另外安装 Python；USB 转串口芯片的驱动仍需正常安装。

1. 插入烧录器。界面每秒刷新串口，并优先选中新插入的设备。多个串口时，请核对名称并手动选择。
2. 点击“选择文件”选择 `.bin`。默认选择 `dist/reCodex-no-joystick-merged.bin`。根据镜像内容识别完整镜像（地址 `0x0`）或本项目应用镜像（地址 `0x10000`），不依赖文件名。
3. 可以先点击“检测芯片”。点击“开始烧录”也会先检测 ESP32-S3，再写入并由 esptool 校验。界面显示实时日志，底部报告结果。
4. 完成后，如果 GPIO0 被手动接地，将其断开并复位设备。

自动发现串口不等于已经识别芯片：芯片识别在点击检测或烧录后进行，可能使设备复位。工具不会仅因插入设备就自动写入。

默认速度为 115200，可选择 460800 或 921600。连接失败时，按住 BOOT 再按 RESET，松开 BOOT 后重试。USB-TTL 须共地、TX/RX 交叉；关闭占用同一串口的串口监视器。

工具仅支持本项目的 ESP32-S3 镜像布局，不支持任意分区布局或单独烧录 bootloader。应用镜像要求设备已安装兼容的完整固件。写入会擦除目标镜像覆盖的扇区，不执行整片擦除，通常可保留布局以外的 NVS 数据。

开发运行：`python flasher/flasher.py`（Python 3.10，pyserial 3.5，esptool 5.3.1）。

重新打包：在项目根目录运行 `flasher/build.bat`（需 PyInstaller）。

本次验证包括文件识别回归测试、GUI 启动、打包后的 esptool 离线命令。真实硬件烧录需使用连接的目标板验证。
